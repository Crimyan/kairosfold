# Kairos

**Job applications, CVs built from a library of blocks and posting timers – in one place, on your own computer.**

**[⬇ Download Kairos 1.0.1 for Windows](https://github.com/Crimyan/kairos/releases/download/v1.0.1/Kairos_1.0.1_x64-setup.exe)** · [All releases](https://github.com/Crimyan/kairos/releases) · [Polska wersja opisu](README.pl.md)

> Works offline, no account, no cloud. Your data stays on your computer. The interface is in Polish for now (English is planned).

## What it does

- **Applications** – track every CV you send: statuses, interviews, follow-ups. Silent applications automatically become **Ghosted** (after 30 days) and move to the archive (after 60). Add a new application by pasting the job ad, a link (Pracuj.pl, LinkedIn, ArtStation, Skillshot, Hitmarker, Work With Indies, SmartRecruiters…) or a screenshot (offline text recognition).
- **Companies and blacklist** – Kairos warns you before you send a CV to a company that doesn't pay, ghosts everyone or asks for free "tests". You already applied there? An ad keeps coming back for months? You'll see it. Share your blacklist with friends (export/import).
- **Library and CV builder** – your experience, skills and tools as reusable blocks with versions. Import an existing CV (PDF/DOCX), build base CVs and tailored copies for a specific offer, 6 templates, ATS check, cover letter, PDF export.
- **Posting** – timers for Reddit, Discord, Facebook groups and forums: when you can post again, text variants and images, a step-by-step posting session with the clipboard.
- **Today and Calendar** – interviews, follow-ups and drafts in one view; month, week and list; export to Google Calendar / Outlook (.ics); Windows notifications with quiet hours.
- **Reports** – status pie chart, funnel (sent → reply → interview → offer), applications over time, which job boards and which CVs get replies; CSV and PDF export.
- **Ctrl+K** – search everything and run commands. **Import** old applications from Excel/CSV. **Daily backups** with one-click restore.

## Install

1. Click **[Download Kairos 1.0.1](https://github.com/Crimyan/kairos/releases/download/v1.0.1/Kairos_1.0.1_x64-setup.exe)** (or open [Releases](https://github.com/Crimyan/kairos/releases) and pick `Kairos_…_x64-setup.exe`).
2. Run the downloaded file. It installs for your user only – no administrator rights needed.
3. Windows SmartScreen may say *"Windows protected your PC"* (the installer is not signed with a paid publisher certificate). Click **More info → Run anyway**.
4. Kairos starts after installation. You'll find it in the Start menu; closing the window hides it to the tray (reminders and timers keep working) – quit it from the tray icon menu.

Requirements: Windows 10 or 11, 64-bit.

## Updates

Kairos checks for a new version shortly after start and every 6 hours. When one is available, a **"↑ Install …"** button appears in the sidebar; click it and Kairos updates and restarts. Your data is kept. You can also check manually in *Settings → Updates*. Only the version file in this repository is requested – nothing about you is sent.

## Your data

Everything is stored in `%APPDATA%\app.kairos.desktop`. Daily backups go to the `backups` folder there – or to any folder you choose in *Settings → Backups* (e.g. OneDrive). To move Kairos to another computer, restore a backup file there.

To uninstall: *Windows Settings → Apps → Kairos → Uninstall*. Your data folder stays until you delete it.
