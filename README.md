# Kairos

**Aplikacje o pracę, CV składane z biblioteki klocków i timery ogłoszeń – w jednym miejscu, na Twoim komputerze.**

> Działa lokalnie, nie wymaga konta, Twoje dane zostają na komputerze.

## Pobierz

Instalator dla Windows 10/11 (x64) jest w zakładce **[Releases](../../releases)** – plik `Kairos_…_x64-setup.exe`.
Instaluje się tylko dla Twojego użytkownika (bez uprawnień administratora). Windows SmartScreen może ostrzec o nieznanym wydawcy (instalator nie ma płatnego certyfikatu wydawcy) – wybierz *Więcej informacji → Uruchom mimo to*.

Zainstalowany Kairos sam sprawdza i instaluje aktualizacje z tego repozytorium.

## Co robi

- **Aplikacje** – śledzenie wysłanych CV: statusy, rozmowy, follow-upy, automatyczna „cisza” i archiwum. Nowa aplikacja z wklejonej oferty, z linku albo ze zrzutu ekranu.
- **Firmy i czarna lista** – ostrzeżenie, zanim wyślesz CV do firmy, która nie płaci albo wykorzystuje „testy”.
- **Biblioteka i Kreator CV** – Twoje doświadczenie i umiejętności jako klocki; CV pod konkretną ofertę w kilka minut.
- **Ogłoszenia** – timery dla Reddita, Discorda, grup na Facebooku: kiedy znowu możesz się wystawić i sesja publikowania krok po kroku.
- **Kalendarz i raporty** – rozmowy, follow-upy, lejek, źródła ofert i skuteczność CV; eksport CSV i PDF.
- **Ctrl+K, import i kopie** – szukanie po wszystkim, import starych aplikacji z Excela/CSV, codzienne kopie zapasowe.

Lista zmian jest przy każdym wydaniu.

## Twoje dane

Wszystko zostaje w folderze `%APPDATA%\app.kairos.desktop`. Brak kont, chmury i AI. Kopie zapasowe możesz kierować do własnego folderu (np. OneDrive).
